# HealthCare

250826 작업물 백업본입니다.

## 주요 기능

- **대시보드**: 건강 목표 설정, 오늘의 영양 요약, 식단·운동·체중 빠른 기록, 변화 추이, 방명록 및 댓글.
- **식단 관리**: 날짜·식사 카테고리별 음식 기록, 음식 검색 및 직접 입력, 칼로리·탄수화물·단백질·지방 분석, 식단 추천, 회원 간 식단 조회와 인기 식단 랭킹.
- **운동 관리**: 운동명·횟수·시간·소모 칼로리 기록과 수정·삭제, 체육시설 지도 및 상세 검색, 시설 정보와 날씨 조회.
- **홈트레이닝**: 운동 영상 검색, 카테고리별 영상 조회, 즐겨찾기 및 코멘트.
- **체중 관리**: 날짜별 체중 기록, 일간·주간·월간 변화 추이, 칼로리와 체중 분석.
- **건강 캘린더**: 식단·운동·체중 기록을 날짜별로 조회.
- **회원 기능**: 회원가입·로그인, 비밀번호 찾기, 회원 정보 수정 및 탈퇴.
- **비로그인 체험**: 식단·운동·체중을 합쳐 총 3회 저장하고, 로그인하면 체험 기록을 이전하여 저장 제한 없이 이용.
- **관리자 기능**: 회원 및 관리자 권한 관리, 식단·운동·체중 기록 관리와 분석, 홈트레이닝 콘텐츠 관리, 비로그인 체험 정책 확인.
- **브라우저 데이터 저장**: IndexedDB에 계정과 건강 기록을 보관하고 기존 브라우저 저장소 데이터를 이전.
